ClipFarm

ClipFarm is a private desktop tool that its owner runs on their own computer to manage their own YouTube channels.

It uses the YouTube Data API and YouTube Analytics API to:

  • schedule uploads of videos to the owner's own channels, and
  • read view and subscriber statistics for those channels.

ClipFarm is not offered to the public. No one else can sign in to it or use it.
